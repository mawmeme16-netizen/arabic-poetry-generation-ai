# Arabic Poetry Generation Using AI

## Project Overview
This project focuses on generating Arabic poetry using artificial intelligence. The model was fine-tuned to generate Arabic poetic verses based on the project's dataset.

## Technologies
- Python
- Qwen2.5 3B
- QLoRA
- Supervised Fine-Tuning (SFT)
- FastAPI
- HTML, CSS, JavaScript
- Firestore

## My Contribution
As a member of the project team, I contributed to:
- Collecting the Arabic poetry dataset.
- Cleaning and preprocessing the data.
- Preparing the dataset for model training.
- Contributing to the model training process.

## Data Preparation
The data preparation process included:
- Handling missing values.
- Cleaning and normalizing Arabic text.
- Removing duplicate entries.
- Filtering and preparing poetry data for training.
