# Arabic Poetry Generation Using AI

An AI-based project for generating classical Arabic poetry
using Large Language Models.

## Project Overview
The project aims to generate Arabic poetry while considering
poetic meter, rhyme, and literary style.

## Technologies
- Python
- Qwen2.5 (3B)
- QLoRA
- Supervised Fine-Tuning (SFT)
- Arabic NLP
